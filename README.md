# Trading Agent: وكيل تداول بالذكاء الاصطناعي (MT5 Demo)

وكيل Claude مستقل يحلل الأسواق ويقرر بنفسه: أي سوق، اتجاه الصفقة، وقف الخسارة، الهدف، المخاطرة، ومتى لا يتداول.
يعمل على **حساب MetaTrader 5 تجريبي** وعلى **محاكي backtest** بالكود نفسه.

> مشروع بحثي على أموال وهمية. لا شيء هنا نصيحة استثمارية، ونجاح الحساب التجريبي لا يضمن أي نتيجة حقيقية.

## الفكرة

```
            ┌──────────────────────────────┐
            │   Claude (Opus 5.5) Agent    │  يُستدعى عند إغلاق كل شمعة قرار (H1 افتراضيًا)
            │  يحلل ← يقرر ← يكتب أسبابه    │
            └──────────────┬───────────────┘
                           │ أدوات (tools)
   ┌────────────┬──────────┼───────────┬──────────────┐
   ▼            ▼          ▼           ▼              ▼
 السوق      الشموع     الحساب     فتح/تعديل/      السجل والدروس
 overview  +مؤشرات    والمخاطر    إغلاق صفقة       (ذاكرة دائمة)
                           │
                  ┌────────▼────────┐
                  │  Risk Manager   │  حدود ثابتة في الكود لا يستطيع الوكيل تجاوزها
                  └────────┬────────┘
              ┌────────────┴────────────┐
              ▼                         ▼
        SimBroker (backtest)      MT5Broker (demo)
```

**أهم المبادئ في التصميم:**
- **حدود المخاطر في الكود وليست في التعليمات:** وقف خسارة إجباري، والوقف يُشدَّد فقط ولا يُوسَّع، وحد مخاطرة لكل صفقة (1%) ولمجموع الصفقات المفتوحة (3%)، وحد خسارة يومي (3%)، وحد أدنى لنسبة الربح إلى المخاطرة، وفلتر للـ spread.
- **الهدف اليومي معلومة وليس إلزامًا.** يوم بلا صفقات نتيجة مقبولة.
- **كل دورة محادثة جديدة.** ذاكرة الوكيل هي سجل الصفقات وملاحظاته المحفوظة (`save_note`)، فلا يتضخم السياق ولا يتراكم الخطأ.
- **مراجعة يومية:** في نهاية كل يوم يراجع الوكيل صفقاته ويحفظ الدروس المدعومة بالأدلة فقط.
- **وكيل عشوائي للمقارنة** (`--agent random`): نفس المخاطر والتكاليف بلا أي مهارة. إذا لم يتفوق Claude عليه بفرق ذي دلالة إحصائية، فلا توجد أفضلية.
- **لا تسرّب للمستقبل في الـ backtest:**
  - الوكيل يرى الشموع المكتملة فقط.
  - التنفيذ على افتتاح الشمعة التالية مع الـ spread.
  - إذا لمست الشمعة الوقف والهدف معًا، يُحتسب الوقف.
  - **التواريخ مخفية** (يرى "Tue 14:00" فقط)، حتى لا يستخدم النموذج ذاكرته عن أحداث تاريخية.
  - البحث في الويب معطّل دائمًا في الـ backtest.

## الوضع الأساسي: Claude Code على Windows باشتراكك (بدون API)

في هذا الوضع Claude Code نفسه هو عقل المتداول، وخادم MCP المحلي هو عيناه ويداه:

```
Windows Task Scheduler ──► scripts\run_routine.ps1 ──► claude -p (اشتراكك)
                                                          │  يقرأ CLAUDE.md + .claude/skills
                                                          ▼
                                          MCP server: trading (Python) ──► MT5 Demo
                                          (بيانات، أجندة اقتصادية، مخاطر، سجل)
```

- **`CLAUDE.md`:** دستور المتداول. شخصيته، والقواعد، وقائمة الاستراتيجيات المسموحة (playbook)، وطريقة التحليل، وتحديد حجم الصفقة حسب جودة الفرصة.
- **`.claude/skills/`:** الروتين اليومي:
  - `daily-prep`: تحضير قبل لندن (الأجندة، الأخبار، الاتجاه والمستويات، خطة اليوم).
  - `trade-cycle`: كل ساعة (إدارة الصفقات، الفحص، التنفيذ).
  - `daily-review`: مراجعة نهاية اليوم.
  - `weekly-review`: مراجعة أسبوعية وخطة الأسبوع.
- **أدوات MCP (16 أداة):** الشموع والمؤشرات، الأجندة الاقتصادية، أوقات الجلسات، فتح وتعديل وإغلاق الصفقات عبر مدير المخاطر، الخطط اليومية والأسبوعية، الملاحظات، ملخصات الدورات.
- **إضافات في مدير المخاطر:**
  - منع الصفقات قبل الأخبار القوية بـ 30 دقيقة وبعدها بـ 15 دقيقة.
  - حد لصافي التعرض لكل عملة، فالصفقات المترابطة تُحسب معًا.
  - حالة اليوم محفوظة في السجل، فكل جلسة جديدة تعرف خسارة اليوم وعدد صفقاته.

### الحارس (Watchdog): يعمل طوال الوقت بدون ذكاء اصطناعي
```powershell
.venv\Scripts\python.exe -m trading_agent watchdog
```
- **يدير الصفقات بين الدورات** حسب خطة كل صفقة: نقطة التعادل (+1R افتراضيًا)، إغلاق جزئي، وقف متحرك بالـ ATR، وإغلاق بعد مدة. الوقف يُشدَّد فقط.
- **تنبيهات سعرية يضعها الوكيل بنفسه** (`set_alert`). عند وصول السعر يوقظ الحارس Claude فورًا بدل انتظار الساعة، بحد أقصى 3 مرات في الساعة.
- **إيقاف كامل اختياري** عند الوصول لحد الخسارة اليومي.
- سجله في `logs\watchdog.log`، و `install_tasks.ps1` يشغّله تلقائيًا عند تسجيل الدخول.

### قائمة الاستراتيجيات كود + إحصاءات حقيقية
```powershell
.venv\Scripts\python.exe -m trading_agent download --bars 150000    # سنوات من شموع M15 من MT5
.venv\Scripts\python.exe -m trading_agent research                  # يقيس كل استراتيجية تاريخيًا
```
- **الاستراتيجيات المبرمجة:** `trend-pullback` و `breakout-retest` و `range-fade`. نفس الكود يقيسها تاريخيًا ويفحص السوق مباشرة، فما يراه الوكيل هو بالضبط ما قيس.
- **طريقة القياس:** الدخول من الشمعة التالية مع احتساب الـ spread والعمولة، ولا تسرّب للمستقبل. النتائج مقسمة حسب الزوج والجلسة وحالة السوق (اتجاه أو نطاق).
- **شرط الاعتماد (`validated`):** يُعتمد الجزء فقط إذا كان رابحًا في فترة الاختبار **وفي الفترة اللاحقة التي لم يُضبط عليها** (آخر 30%)، مع عدد صفقات كافٍ.
- **في كل دورة** يستدعي الوكيل `scan_setups` فيرى الإشارات مع "بطاقة الأفضلية"، ويحدد حجم المخاطرة على أساسها.
- **على بيانات عشوائية** تخرج كل الاستراتيجيات بلا أفضلية معتمدة. هذا اختبار أن النظام لا يخدع نفسه.

### أدوات المتداول المحترف (30 أداة)
| المجال | الأدوات |
|---|---|
| التنفيذ | `open_trade`، `place_pending_order` (Limit/Stop مع انتهاء صلاحية)، `cancel_pending_order`، `modify_trade`، `close_trade`، `set_trade_management` |
| الرؤية | `view_chart` (صورة الشارت مع المستويات والصفقات والتنبيهات)، `get_market_structure` (القمم والقيعان، مناطق الدعم والمقاومة، قمم وقيعان اليوم والأسبوع السابق، نطاق آسيا، المدى اليومي المتوسط)، `get_candles`، `get_market_overview` |
| السياق | `get_intermarket` (عوائد 2y و10y ومنحناها، الدولار، VIX، النفط، S&P)، `get_positioning` (تقارير COT ونسب عملاء OANDA)، `get_economic_calendar`، والبحث في الويب |
| الأفضلية | `scan_setups` مع بطاقة الأفضلية، `get_edge_stats` |
| المخاطر | تقليل المخاطرة تلقائيًا عند التراجع، حدود يومية وأسبوعية وشهرية، تعرض العملات يشمل الأوامر المعلّقة، منع الدخول وقت الأخبار |
| القياس | `get_performance_diagnostics`: صدق احتمالات الوكيل (Brier)، الإشارات المأخوذة مقابل المتروكة (سجل الظل)، أقصى ربح وأقصى خسارة لكل صفقة (MAE/MFE) |
| الذاكرة | الخطط اليومية والأسبوعية، الملاحظات، ملخصات الدورات، التنبيهات |

### متغيرات بيئة اختيارية
```powershell
setx TELEGRAM_BOT_TOKEN "..." ; setx TELEGRAM_CHAT_ID "..."   # إشعارات على جوالك (من @BotFather)
setx OANDA_API_TOKEN "..."                                  # نسب مراكز عملاء OANDA (حسابك > Manage API Access)
setx FRED_API_KEY "..."                                     # اختياري: الـ API الرسمي لبيانات FRED (مجاني)
```
بدون هذه المتغيرات يعمل كل شيء، وتعيد الأداة المعنية رسالة توضح ما ينقصها.

`research` يسحب التاريخ من MT5 تلقائيًا ويضيف الجديد فقط. للوصول لسنوات من البيانات، اضبط في MT5 الخيار:
Tools ← Options ← Charts ← Max bars in chart = Unlimited


افتح MT5 وسجّل الدخول للحساب التجريبي.

### التجربة اليدوية
داخل مجلد المشروع شغّل `claude`، ثم اكتب `/daily-prep` أو `/trade-cycle`. ستشاهد الوكيل يحلل ويقرر أمامك.
يمكن أيضًا إضافة نفس الخادم لـ Claude Desktop من الإعدادات: Developer ← Edit Config، بنفس محتوى `.mcp.json` ومسار `--config` كامل.

### التشغيل التلقائي
```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_tasks.ps1 -DailyPrep 09:30 -DailyReview 00:15
```
- الأوقات بتوقيت جهازك. اضبط `DailyPrep` قبل افتتاح لندن بنصف ساعة تقريبًا.
- السجلات في `logs\`.
- للإيقاف الطارئ أنشئ ملفًا اسمه `STOP` في مجلد المشروع.
- **حدود الاشتراك:** كل دورة تستهلك من حصة اشتراكك. إذا وصلت للحد، استخدم `-CycleEveryHours 2` أو `-Model sonnet` للدورات الساعية، واترك Opus للتحضير والمراجعة.

## الاستخدام

### 1. تجربة سريعة بدون بيانات حقيقية (أي نظام تشغيل)
```bash
python -m trading_agent sample-data --days 120          # بيانات عشوائية تمامًا لاختبار النظام فقط
python -m trading_agent backtest --agent random --random-p 0.3 --seed 1
```
على بيانات عشوائية، أي وكيل يجب أن يخرج بلا أفضلية تقريبًا ويخسر قليلًا بسبب التكاليف. هذا اختبار سلامة للمحاكي نفسه.

### 2. تحميل بيانات تاريخية حقيقية من MT5 (على Windows)
```bash
python -m trading_agent download --timeframe M15 --bars 100000
```
البديل: صدّر الشموع يدويًا من MT5 (View ← Symbols ← Bars ← Export) واحفظها باسم `data/EURUSD_M15.csv`.
حمّل سنة على الأقل قبل بداية الاختبار، لأن مؤشر EMA200 على الإطار اليومي يحتاج 200 يوم من التاريخ.

### 3. Backtest للوكيل الذكي
```bash
python -m trading_agent backtest --agent claude --max-cycles 50 --label "first-try"
python -m trading_agent backtest --agent random --seed 1 --label "baseline"
python -m trading_agent report
```

### 4. تشغيل مباشر على الحساب التجريبي (Windows)
```bash
python -m trading_agent live --agent claude -v
```
للإيقاف الآمن أنشئ ملفًا باسم `STOP` في نفس المجلد، أو اضغط Ctrl+C.
فعّل `agent.web_search: true` إذا أردت أن يقرأ الوكيل الأخبار والأجندة الاقتصادية في التشغيل المباشر.

## التكلفة

كل دورة قرار تستدعي Claude مرة أو أكثر (الوكيل يطلب الشموع ويحلل ثم يقرر):
- دورة بلا صفقة: غالبًا 2–5 استدعاءات.
- إطار H1 على 4 أزواج: حوالي 120 دورة أسبوعيًا.
- للتقليل: `--max-cycles`، أو `decision_timeframe: H4`، أو `effort: medium`.
- الـ system prompt والأدوات عليها prompt caching، فالجزء الثابت يُحسب بعُشر السعر.
- استهلاك الـ tokens يُسجَّل لكل دورة ويظهر في `report`.

## كيف تحكم على النتائج

| السؤال | الأداة |
|---|---|
| هل متوسط R أكبر من صفر بدلالة إحصائية؟ | `t_stat_avg_r` و `p_value_edge` في التقرير |
| هل يتفوق على العشوائي بنفس التكاليف؟ | backtest لـ `random` بعدد صفقات قريب |
| هل النتيجة ليست صدفة فترة معينة؟ | اختبر فترات مختلفة لم تُستخدم في تعديل الـ prompt |
| هل تستمر مباشرة؟ | شغّل Demo لأسابيع وقارن |

قاعدة تقريبية: أقل من 200 صفقة لا تكفي لأي حكم قوي. وإذا عدّلت الـ prompt بعد كل اختبار، فاحتفظ بفترة بيانات أخيرة لا تختبر عليها إلا مرة واحدة في النهاية.

## هيكل المشروع

```
trading_agent/
  agent/claude_agent.py   حلقة Claude (tool use، adaptive thinking، caching، refusal fallback)
  agent/tools.py          أدوات الوكيل وتنفيذها
  agent/prompts.py        الـ system prompt ورسائل الدورات والمراجعة
  agent/random_agent.py   الوكيل العشوائي للمقارنة
  broker/simulated.py     محاكي backtest بلا تسرّب للمستقبل
  broker/mt5.py           الربط مع MetaTrader 5
  risk.py                 مدير المخاطر (حدود ثابتة)
  journal.py              سجل SQLite لكل صفقة وقرار وملاحظة
  market.py, indicators.py  تجهيز البيانات والمؤشرات
  stats.py                الإحصاءات واختبار الدلالة
  runner.py, __main__.py  التشغيل وسطر الأوامر
tests/                    اختبارات المحاكي والمخاطر وحلقة الوكيل
```

## الخطوات القادمة المقترحة
- أجندة اقتصادية منظمة (قرارات الفائدة، NFP، CPI) كأداة، مع منع الصفقات قبل الأخبار القوية.
- تشغيل عدة نماذج أو إعدادات على نفس البيانات ومقارنتها.
- لوحة ويب تعرض الرصيد والصفقات وأسباب كل قرار.
