## 1. The owner's goal (in their words, summarised)
An autonomous AI trader that analyses markets, decides by itself (market, timing, size, stops,
targets, when NOT to trade), follows the news and statistics, has a daily goal but no emotions,
and trades a **demo account** so its behaviour can be observed. The ambition is a "veteran
professional" trader, not a toy experiment. The owner wants it to run **locally on Windows inside
Claude Code / Claude Desktop with their Claude subscription, without an API key**.

## 2. Key decisions and why (decision log)
1. **Binary options / OTC (Pocket Option, Quotex) were dropped entirely.** Reasons explained to the
   owner: OTC prices are generated by the broker, which is also the counterparty; payouts below
   100% need 54-71% win rates just to break even; their terms forbid bots. The owner agreed.
2. **Spot FX/CFD on MetaTrader 5 demo** was chosen instead (fair maths: costs are only spread and
   commission and shrink on longer timeframes, asymmetric R:R possible, official Python API).
   The owner plans an **OANDA MT5 demo** (demo server name usually `OANDA_Global-Demo-1`). OANDA's
   entity depends on country (BVI entity is weaker protection); only matters for real money later.
3. **Timeframes: H1 decisions** (M15 for timing, H4/D1 context), not seconds/minutes.
4. **Brain = Claude Code itself** (subscription). The trading desk is exposed as an **MCP server**
   (`trading_agent/mcp_server.py`); routines are **skills** in `.claude/skills/`; Windows Task
   Scheduler runs `claude -p` for each routine (`scripts/run_routine.ps1`). An API-based agent
   (`trading_agent/agent/claude_agent.py`) also exists, only for automated backtests.
5. **Hard risk limits live in code** (`trading_agent/risk.py`), never only in prompts.
6. **Honesty principle repeatedly agreed with the owner:** no prompt makes a trader "better than 99%";
   an edge must be discovered and proven statistically. Hence the playbook statistics, the shadow
   book, calibration scoring and the research lab with strict anti-overfitting gates.
7. **Data:** live analysis always uses live broker data through MT5 (no downloads). Historical data
   is downloaded/cached locally ONLY for research (fast, reproducible, repeatable tests). `research`
   and `lab` commands refresh history from MT5 automatically.
